Kubernetes 入门实战

这套教程依据 Nigel Poulton 的《The Kubernetes Book》2026 版和配套示例仓库整理而成。 每一章都从「为什么需要它」讲起，配上大量示意图，再用仓库里真实的 YAML 文件一步步动手—— 从第一个 Pod，到 Gateway API、StatefulSet、RBAC，再到生产环境的安全实践。

Kubernetes 是什么

一句话：Kubernetes 是一个编排器。你告诉它「我想要什么」——比如「这个应用要 10 个副本，对外开 8080 端口」， 它就负责把应用部署到一群机器上，坏了自动修，忙了自动扩，要升级就一个个平滑替换。

⎈

云的操作系统

就像 Linux 抽象掉一台服务器的硬件，Kubernetes 抽象掉整片云：AWS、Azure、GCP 还是自家机房，用法都一样。

📦

以容器为单位

应用打包成容器，包进 Pod，再交给 Deployment 等控制器管理。

📝

一切皆 YAML

所有配置都是声明式的 YAML 文件，可以放进 Git 做版本管理和审查。

🌐

行业事实标准

由 Google 于 2014 年开源，现由 CNCF 管理，已十余岁，每年约 3 个版本。

这套教程写给谁

  • 听说过容器、但没用过 Kubernetes 的开发者：每个概念都配图解释，术语出现时就地翻译。
  • 需要上手运维集群 的工程师：每章都有可直接运行的命令和真实输出，知道「敲下去会看到什么」。
  • 准备系统梳理知识 的人：从架构原理到安全实践，覆盖原书全部 16 章，另有排错、探针与自动扩缩、从源码到上线、Job/CronJob/DaemonSet 四篇补充。
ⓘ 需要什么前置知识

会用命令行（cd、ls、编辑文件）就够了。知道 Docker 和容器是什么会更轻松，但不是必须——第 1 章会从头讲。 YAML 的语法很简单：缩进表示层级，- 表示列表项，读几个例子就会了。

学习路线

怎么用这套教程

  • 按顺序读。后面的章节会用到前面的概念。第 1、2 章是理论地图，第 3 章装好环境后就一路动手。
  • 亲手敲命令。代码块右上角有「复制」按钮；终端会话里只会复制 $ 后面的命令，不会把输出也复制进去。
  • 留意彩色提示框。蓝色是补充说明，绿色是技巧，红色是坑，橙色是必须记住的要点。
  • 做每章末尾的练习。看懂和做出来之间的差距，比你想象的大。

示例代码与环境

所有 YAML 文件和示例应用都在原书的 GitHub 仓库里（本教程也位于这个仓库的 docs/ 目录）：

$ cd TKB
$ git fetch origin
$ git checkout -b 2026 origin/2026
环境适用章节
Docker Desktop 内置的多节点（kind）集群除 Gateway API 和存储外的所有示例
云上托管集群（原书使用 Akamai LKE）第 8 章 Gateway API、第 10 章存储、第 12 章 StatefulSet
💡 写给 Windows 用户

大多数命令在 Linux、Mac、Windows 上都能用。书中长命令用反斜杠 \ 换行，Windows 上要么去掉反斜杠写成一行，要么换成反引号 `。 其他差异会在用到的地方单独说明。

ⓘ 关于大写

和原书一样，本教程把 Kubernetes 对象名的首字母大写，比如 Pod、Service、Namespace。这样你能分辨我们说的是 Kubernetes 的 LoadBalancer 对象，还是泛指云上的「负载均衡器」。

★ 一句话总结

如果你只记住一件事：你用 YAML 声明期望状态，Kubernetes 的控制器永不停歇地把现实调和成你想要的样子。 接下来的每一章，都是这句话在不同对象上的展开。
